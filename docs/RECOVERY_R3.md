# R3 — recovered model to GLB and native Godot scene

## Scope and status

R3 implements a model conversion bridge. It does not run the game, recover missing
server code, acquire the full supplied APK, or claim a playable Android port.
R1/R2's full-input acceptance gate is unchanged. All models generated by CI are
explicit synthetic fixtures, not newly extracted game assets. The original client
source trees and existing full-APK workflow trigger are unchanged.

## Convert a captured model

After transferring, capturing and verifying the actual APK and building its R2
object graph, select a GameObject or Transform by its catalog identity:

```bash
python -m pip install -r requirements-recovery.txt
python tools/recovery_model.py recovery/snapshot \
  --root-object OBJECT_SHA256_ID --out recovered-assets/model-001
```

The output is `model.glb` plus `report.json`. The report binds the model hash to
the input APK hash and root identity, records exported counts and omitted
components, and explicitly denies shader equivalence and gameplay completion.
Existing output directories are refused. Conversion must finish before the
output directory is created; raw capture and source code are not overwritten.

The adapter validates raw capture and graph records first, then reparses the
original serialized members through a catalog-scoped UnityPy environment. The
reparsed object bytes must match their stored hashes. UnityPy's MeshHandler
provides vertex channels directly; OBJ is not used as an intermediate because it
would lose skinning. Triangle submesh ranges and baseVertex offsets are validated
and applied explicitly. Reused names never select objects or output paths.

## Supported model subset

The bridge supports static MeshRenderer/MeshFilter bindings and
SkinnedMeshRenderer models with four bone weights per vertex. It retains the
selected hierarchy, translation/quaternion/scale, triangle submeshes, positions,
normals, tangents, UV0, vertex colors, material slots, ordered joints, inverse bind
matrices and skeleton root when present. Bones must be inside the selected
subtree. Every required mesh, material, texture and bone reference must resolve.
Nonfinite geometry, invalid indices, missing arrays, zero scales, singular binds,
non-normalized quaternions, and invalid weights are rejected.

This stage does **not** export animation curves, animator controllers, morphs,
variable-influence skins, GPU-skinning textures, particles, UI layout, gameplay
scripts, collision behavior or scene logic. Unsupported components are recorded;
unsupported geometry/skinning formats fail. Select a larger root when skeleton
joints fall outside the subtree instead of synthesizing missing bones.

Materials are deliberately limited to a **base-color preview**: `_Color` and
`_MainTex` when present, with the exact texture reference and decoded PNG. This is
not the original Unity shader. Texture transforms other than identity are rejected;
normal maps, metallic/smoothness, transparency modes and custom shader inputs are
not recreated. White/default base color when `_Color` is absent is a preview
convention, not evidence about the original shader. Inspect representative real
assets before judging visual fidelity.

## Coordinate and skinning contract

The single basis reflection is C = diag(-1, 1, 1, 1): positions/normals reflect X,
quaternions become (x, -y, -z, w), local scales remain unchanged, and each inverse
bind matrix becomes C * B * C. Internal matrices are row-major; MAT4 accessors are
serialized column-major. Triangle winding is reversed. UV V is flipped for the
exported top-origin PNG; tangent direction reflects X, while tangent W is unchanged
because the basis reflection and V flip both reverse tangent handedness.

Tests compare converted transforms and posed skinning against independent NumPy
matrix calculations using nonidentity transforms, two bones, unequal weights and
a changed bone pose. This verifies the conversion equation, not the behavior of
an unobserved game animation. Bind poses are never replaced by identity to hide
unavailable data.

## Independent validation and native scene bridge

The `Model bridge` workflow installs the pinned UnityPy and Lua versions and runs
all regression tests without runtime-dependent skips. It generates four GLBs:
normalized static/skinned fixtures and actual Unity serialized static/skinned
fixtures processed through capture -> graph -> model conversion. The latter use
real type writers, real PPtrs and real mesh vertex channels, not mocked exporters.

Each GLB is checked with pinned Khronos glTF-Validator 2.0.0-dev.3.10 and imported
by pinned Godot 4.4.1. Godot checks mesh/triangle/bone/skin counts, geometry bounds,
material presence and skin weight/binding arrays; saves a native PackedScene;
reloads it and repeats the checks. A failed native import or lost binding exits
nonzero. Godot's release archive is verified against its published SHA-512 list.
The headless harness is in `godot/`, not an empty game advertised as a port.

To invoke the same native conversion on a GLB with an expected-count manifest:

```bash
godot --headless --path godot --script scripts/verify_model.gd -- \
  /absolute/model.glb /absolute/model.expected.json /absolute/model.godot.json
```

The expectation file contains integer `mesh_instances`, `triangles`,
`skinned_instances` and `min_bones`. The harness produces a JSON verification report
and a `.tscn` beside it. CI artifacts contain these native scenes, GLBs, parser
reports, fixture inputs and test logs. Headless import is not a rendered visual
comparison, a device performance test, an Android export, or proof of game parity.

## Remaining gates

Capture the actual supplied APK and retain its complete snapshot. Check real model
counts, unresolved dependencies, original `gameres` mappings and representative
textured/skinned exports. Extend decoding only from those measured formats, then
recover animation curves and custom material/GPU-skin behavior. Validate the
critical client logic separately. A Godot Android gameplay slice must use those
verified game inputs and pass actual export/device tests before it is called a port.
